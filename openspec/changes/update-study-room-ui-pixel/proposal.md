## Why
- 现有图书馆界面以渐变+毛玻璃风格实现，难以满足希望使用像素风主题的主播需求。
- UI 与业务逻辑耦合在现有 `app.js` 中，后续要扩展多套皮肤或复用交互逻辑较困难。
- 审美与布局需要针对低分辨率 OBS 场景进一步优化，确保像素风仍具可读性与可维护性。

## What Changes
- 重构图书馆前端，将业务逻辑（状态渲染、事件处理）抽离为独立模块，可供不同皮肤复用。
- 设计并实现默认像素风皮肤，包括像素字体、网格化卡片、低色深调色板、像素化图标等，同时遵循“左侧主图书馆 / 右侧座位板”双栏布局。
- 提供皮肤切换/注册机制，允许后续加载其它主题或自定义皮肤包。
- 在 `frontend` Vue 工程中新增独立入口（多页面或子应用），使后续皮肤开发能够基于现有 Vue 构建链路进行组件化迭代。
- 左侧图书馆区域支持加载外部提供的座位图背景，确保后续可将座位信息映射到图片上的热点；模板发布遵循 `data/custom_public/templates` 规范，可直接在后端模板列表中选择。

## Impact
- 前端将新增 `src-library` 目录（与 `src` 同级）承载图书馆页面组件与主题，实现逻辑/样式解耦，同时在 Vue CLI 配置中引入新的构建入口。
- 需要更新文档，指导如何开发与切换皮肤，并说明静态资源打包方式。
- 可能影响现有截图/说明，需要同步更新 README 或 wiki 中的图片示例。
